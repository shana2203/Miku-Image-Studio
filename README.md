# Miku Image Studio — Hybrid 3.3 (beta)

Generador de ilustraciones anime para Windows 11 con PySide6, ComfyUI offline, OpenAI opcional y Real-ESRGAN Anime 6B.

## Funciones
- Generación de 1 a 8 imágenes independientes con personajes, poses y escenarios aleatorios.
- Illustrious XL principal y NoobAI XL opcional.
- Escalado 4×, nitidez 30%, importación y lotes.
- Exportación PNG y galería.

## Requisitos
Windows 11 x64, NVIDIA CUDA, 16 GB RAM recomendados, 35 GB libres e Internet para la instalación inicial. El modo online requiere clave API propia y puede generar cargos.
