# Contribuir / Contributing

La aplicación está en fase beta. Se agradecen informes de errores (versión de Windows, GPU, salida de `Instalar.bat` y `motor.log`, **sin claves ni datos personales**) y pull requests con mejoras.

Para cambios importantes, abrí primero un issue explicando el problema y la propuesta. Las contribuciones no implican que el proyecto esté publicado bajo una licencia abierta; la licencia se definirá antes de aceptar contribuciones externas.
